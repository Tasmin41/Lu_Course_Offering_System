# LU Course Offering System

A web-based system for managing course offerings at Leading University, Sylhet, Bangladesh. Developed as my final year project for the B.Tech in Computer Science and Engineering.

## Features

**Course Offering Committee**
- Offer courses each semester
- Track the total number of courses offered
- See how many courses are assigned to each instructor

**Students**
- Choose courses to take each semester, including the course teacher
- Browse the faculty members through the website

## Built with
- PHP (backend)
- HTML, CSS (frontend)
- MySQL

## Run locally
1. Clone the repository: `git clone https://github.com/Tasmin41/Lu_Course_Offering_System.git`
2. Place the folder in your local server directory (e.g., XAMPP `htdocs`).
3. Import the database file (if included) into MySQL.
4. Start Apache and MySQL, then open `http://localhost/Lu_Course_Offering_System`.
